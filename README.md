# 温故

把课程视频、录音、PDF 和 PPT 变成能复习的材料。提取在你自己的 Mac 上完成，免费，不上传到任何地方。

考前要过的材料太多——几十小时的讲座视频、几百页的 PPT 和 PDF——来不及全部重看。温故不做"AI 一键总结"，因为总结会删减、会出错，而且你没法核对。它给你三样东西，每一条内容都能点回原处：

| | 是什么 | 谁来生成 |
|---|---|---|
| **原文全文** | 每份材料的完整文字。视频每段带时间戳，点一下跳到那一秒；PDF 标页码，PPT 标张数 | 温故，在本机完成 |
| **复习文档** | 详细的复习文档：定义、推导的每一步、老师的例子、自测题，每条标出处 | 你自己的 AI（ChatGPT / Claude），按温故写好的任务说明 |
| **精读指引** | 哪些片段、哪些页必须亲自看，为什么；哪些读文档就够；哪些可以跳过 | 自动线索由温故生成；完整指引由你的 AI 写 |

## 安装（Mac，一行命令）

打开「终端」，粘贴下面这一行，按回车：

```
curl -fsSL https://raw.githubusercontent.com/Xqino1/wengu/main/install.sh | bash
```

它会把温故装到 `~/温故`（不在 iCloud 里，打开快），把「温故」放进「应用程序」文件夹，桌面和程序坞（Dock）上也各放一个图标，然后自动打开。不需要 Homebrew，不需要管理员密码。安装时要下载约 1GB 的组件，等几分钟；之后点图标几秒就开。

想让 AI 带着装：把 [发给朋友.md](发给朋友.md) 里那段话粘贴给 ChatGPT。

## 使用

1. 点桌面、程序坞或「应用程序」里的「温故」，浏览器里先打开开始页：背景是古今中外讲学习的名言和你自己讲稿里的句子，每句标着出处，分三层慢慢往上飘，滚动可以快进或倒回；点讲稿里的句子回到讲课里的那一刻。中间两个入口：「新建复习包」和「所有复习包」。用完点「退出」。
2. 粘贴 YouTube 链接（整个播放列表也行），或者把视频、录音、PDF、PPTX 拖进去，点「开始提取」。
3. 提取完进入复习包页面：原文全文马上能看；点「复制给 AI 的话」，发给你的 AI，它写的复习文档和精读指引会自动出现在材料表里。写好以后，每一讲下面会多一条细细的时间轴，复习文档引用过的时刻用荧光黄标出来，点一下就跳到原文那一刻。
4. 点任意一份进入阅读页：左边换成这个复习包的材料目录，右边是本页目录，公式按数学排版显示。点文档里的时间戳，右边会翻出原文那一段让你核对，再点「看视频这一段」跳到视频那一秒（按住 ⌘ 点时间戳直接跳）。「显示」里可以调字号、换宋体或黑体、换护眼或夜间背景；可以打印或存成 PDF。

「所有复习包」里每个复习包是一叠讲义，材料越多叠得越厚，封面上有前几讲的标题和写到哪了（实心小方块是已经写了复习文档的）。复习包多了以后可以搜索、置顶、按课程分组、归档；进了复习包，左边也有同样的列表方便切换。不要的复习包在复习包页点「删除」：它会先进「废纸篓」，7 天后自动彻底删除，在那之前随时能恢复。输出语言默认跟随课程语言（英文课出英文文档），也可以选中文讲解或双语。

速度：有字幕的视频几秒一条。没字幕的要做语音识别，M 芯片 Mac 上大约是视频时长的五分之一（第一次会下载约 1.6GB 的识别模型）。

## 需要知道的限制

- 只支持 Mac。Intel Mac 能用，但语音识别慢很多。
- 复习文档和精读指引的质量取决于你用的 AI。任务说明要求它标出处、不补原文没有的内容、不猜板书，但它仍然可能出错——**出处就是让你核对用的**。
- 视频文字来自字幕或语音识别，会有错词和错数字。只用和视频所说语言一致的字幕（别的语言的字幕是翻译，对不上原话）；判断不出视频说什么语言时直接做语音识别。每份材料的「文字来源」写明用的是哪种语言的字幕。
- 文字稿看不到板书和图表。老师指着画面讲的地方，要回去看视频，精读指引会把这些位置标出来。
- 需要登录才能看的课程视频（学校平台）不能用链接，下载到本地后拖进去。
- PPT、Keynote、Word 要先导出成 PDF 或 PPTX。扫描版 PDF 读不出文字。
- YouTube 偶尔要求人机验证，温故会借用 Chrome 的登录状态；Mac 弹出钥匙串提示时点「始终允许」。

## 常见问题

**关掉了怎么再打开？** 点桌面、程序坞或「应用程序」里的「温故」。只关浏览器页面的话，温故还开着，点图标会直接回到页面。
**点图标没反应？** 会弹窗说明原因，点「用终端打开」能看到详细信息；记录在 `~/温故/.cache/启动记录.txt`。
**复习包存在哪？** `~/温故/输出/`，每次提取一个文件夹。删掉的在 `~/温故/输出/废纸篓/`。
**删错了怎么办？** 删完马上点提示条里的「撤销」；或者去「所有复习包」右上角的「废纸篓」点「恢复」。7 天内都能恢复。
**怎么更新？** 对 Codex 说「更新温故」（安装时教过它）；没有 Codex 就在终端再运行一次安装命令。更新会先关掉正开着的温故（正在提取时不更新），换上新版并删掉新版里已经没有的旧文件；「输入」「输出」和你自己放进 `~/温故` 的文件不会被动。
**怎么卸载？** 删掉 `~/温故` 文件夹、「应用程序」和桌面上的「温故」，再把它从程序坞里拖出去。用 Codex 的话，再打开 `~/.codex/AGENTS.md`，删掉「温故：开始」和「温故：结束」两行标记之间的那一段。
**安装程序动了 Codex 的什么？** 只在 `~/.codex/AGENTS.md` 末尾加了一小段，夹在两行标记之间，告诉 Codex「更新温故」就是运行安装命令。每次安装都换成最新的那段，不会重复，别的内容不动。没装 Codex 的电脑不会写。

## 开发

单文件 Python（`wengu.py`）加一个网页（`ui.html`），依赖由 [uv](https://docs.astral.sh/uv/) 按文件头自动安装。

```
uv run wengu.py            # 启动界面
uv run wengu.py --cli      # 命令行模式
uv run --with pytest --with pypdf --with python-pptx --with fpdf2 --with opencc-python-reimplemented --with yt-dlp --with markdown pytest -q
```

MIT 许可。用到的开源项目：yt-dlp、mlx-whisper / faster-whisper、pypdf、python-pptx、OpenCC、Python-Markdown、KaTeX（随仓库放在 `vendor/katex`，离线可用）。
